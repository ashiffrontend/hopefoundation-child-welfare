# HopeFoundation Child Welfare

> **"Together We Build Brighter Futures."**  
> A premium, accessible, and responsive NGO frontend application crafted with pure HTML5, CSS3, and Vanilla JavaScript (ES6).

---

## 🌟 Overview

**HopeFoundation Child Welfare** is an Apple-inspired, government-grade non-profit platform dedicated to advancing child education, nutrition, healthcare, and sustainable village development. Designed from the ground up without frameworks or complex build pipelines, this project can be opened directly in any browser or deployed with zero configuration on platforms like **Vercel**, **GitHub Pages**, and **Netlify**.

---

## 🚀 Key Features

- **Pure Static Architecture**: 100% Vanilla HTML5, CSS3, and modern ES6 JavaScript. No React, no Tailwind, no node_modules required.
- **Apple-Inspired Modern UI**: Soft color palette (`#0EA5A4`, `#2563EB`, `#F59E0B`, `#16A34A`), generous whitespace, glassmorphism (`backdrop-filter: blur`), and refined typography.
- **3-Zone Sticky Navigation**: Wordmark brand anchor, clean single-line links with active scroll highlights, and primary CTA.
- **Theme Switcher**: Smooth Light and Dark Mode toggle with `localStorage` persistence and OS-level color scheme detection.
- **Scroll Depth Progress Bar**: Real-time reading depth bar at the top of the viewport.
- **Animated Statistics Counters**: Responsive counters (10,000+ Children, 500+ Volunteers, 250+ Partner Schools, 50+ Villages, ₹2M+ Funds Raised).
- **Interactive Programs Filter**: 8 detailed initiatives filterable across Education, Nutrition, Healthcare, and Community with modal inspection.
- **Donor Transparency Donut Chart**: Pure SVG interactive chart with hover highlights, live category inspector, and animated spending bars.
- **Tax Receipt Generator (Demo)**: Section 80G tax exemption verification form with live formatted printable certificate and instant text download.
- **Interactive Donation Calculator**: Preset impact tiers (₹500, ₹1000, ₹2500, ₹5000), custom amount input, frequency toggle, and checkout modal.
- **Volunteer Enrollment Engine**: Form validation with onboarding ID badge generation and interactive success modal.
- **Testimonials Auto Carousel**: 5-star verified review carousel with auto-rotation, pause on hover, manual arrows, and dot indicators.
- **Full-Screen Photo Lightbox**: Modal viewer with keyboard controls (`Escape`, `ArrowLeft`, `ArrowRight`).
- **Accessible FAQ Accordion**: Keyboard and screen-reader friendly collapsible questions.
- **Floating Action Dock**: Instant WhatsApp messaging, telephone hotline, and back-to-top smooth scrolling.
- **SEO & Structured Data**: OpenGraph tags, Twitter Card metadata, and Schema.org `NGO` JSON-LD structured data.

## ⚡ Deployment on Vercel (Zero Configuration)

This repository is tailored for immediate deployment on **Vercel**:

1. Push or import this repository into your GitHub account.
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select your repository.
4. **Build & Development Settings**: Leave all settings at their defaults:
   - **Framework Preset**: *Other*
   - **Build Command**: *None*
   - **Output Directory**: *None* (Root `/`)
5. Click **Deploy**. Your static website will be live in seconds!

## 💻 Local Development

You can run this website locally without installing any tools:

1. **Directly in Browser**: Double-click `index.html` to open it in your browser.
2. **Using Python**:
   ```bash
   python3 -m http.server 3000
   ```
3. **Using Node**:
   ```bash
   npx serve .
   ```
